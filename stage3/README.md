# Stage 3 — Advanced SQL Analytical Queries

## Overview

This directory contains the third stage of the **Information Systems and Databases (SIBD)** course project (2025/2026).

While Stages 1 and 2 focused on full-domain E-R modeling and complete relational database design, **Stage 3** evaluates advanced querying capabilities in Oracle SQL using a standardized, simplified relational schema provided by the course professors.

This stage of the project earned a grade of **19.7 / 20.0**.

## File Structure

| File                | Description                                                                                    |
| :------------------ | :--------------------------------------------------------------------------------------------- |
| **`schema.sql`**    | Official DDL schema provided by the department (`artista`, `album`, `utilizador`, `possui`).   |
| **`functions.sql`** | Helper PL/SQL function (`decada_de_ano`) required for dynamic decade grouping.                 |
| **`queries.sql`**   | The complete SQL script submitted for evaluation, containing the 4 complex analytical queries. |

> **Note on Naming Conventions:** The database schema and table names in this directory are preserved in **Portuguese** as provided by the university evaluation environment to guarantee 100% execution compatibility with the graded queries.
